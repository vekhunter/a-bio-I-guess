# Practice with JavaScript Array Methods — Interactive Learning Page

This project is a modern, instructional webpage designed to help JavaScript beginners learn and practice array methods, template literals, and dynamic DOM manipulation. Inspired by BYU–Idaho WDD 131 learning modules.

## Features
- Live demonstrations of forEach, map, filter, indexOf, reduce
- Use of template literals and DOM injection
- Arrays of objects and dynamic HTML output
- Console-based and dynamic HTML examples
- Clean, academic, responsive design

## How to Use
1. Open `index.html` in your browser.
2. Follow each section to learn and interact with the examples.
3. Open your browser's DevTools console to view additional outputs.

## Sections
- Hero & Introduction
- forEach() Demonstration
- map() + Template Literals + DOM Injection
- GPA Conversion Example (switch + map + reduce)
- filter() Example
- indexOf() Example
- Array of Objects — Student Directory
- Console Output Notes
- Footer
